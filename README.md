# The Sovereign Mind

A manifesto for the era of thinking machines.

Live site: https://johnhubble.github.io/sovereign-mind/

## Editing

Plain HTML + CSS, no build step. Edit `index.html`, `styles.css`, or `script.js` and push to `main`. GitHub Pages serves from the repo root.

## Local preview

Open `index.html` directly in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```
